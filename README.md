# AI Number Guessing Challenge

A math based low number tracking program created using Python that creates a game environment where a user plays against a system that generates a random secret number with strict limits.

## 🚀 Key Features

* **Dynamic Range Target:** Uses boundary inputs to pick a secret number between 1 and 50.

* **Resource Constraints (Lives Tracker):** Has a 5 lives limit system stopping the program completely when the lives are used up.

* **Algorithmic High-Low Feedback:** Gives direction updates (" High" or "Too Low") to help the user find the answer in a logical way.

## 💻 How to Run Locally

1. Copy this repository.

2. Open a terminal inside the folder. Run:

```bash

python guesser.py

```

## 🇰🇷 GKS Engineering Profile Alignment
